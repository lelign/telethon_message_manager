# telethon_message_manager 
 
фильтрация спама по словарю администратора канала телеграмм 

фильтрация абсценной лексики по соотв. словарю 

поддержка функции <бан> по команде администратора (admin's replay "to ban" for unwanted message)

удаление нежелательных сообщений из группы, привязанной к комментариям новостей телеграм канала

ведения лога событий (сообщения, бан, ошибки)

построено с использованием API Telethon, используется в Windows (python3.14)
