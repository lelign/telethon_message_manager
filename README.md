# telethon_message_manager \n
фильтрация спама по словарю администратора канала телеграмм \n
фильтрация абсценной лексики по соотв.словарю 
поддержка функции <бан> по команде администратора
удаление нежелательных сообщений из группы, привязанной к комментариям телеграм канала
ведения лога событий сообщений, бана и ошибок
построено с использованием API Telethon, используется в Windows (python3.14)
